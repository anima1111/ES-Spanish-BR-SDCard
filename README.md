# Bible Reader content — ES-Spanish

This repository contains the Bible Reader SD-card content for **ES-Spanish**.

## Directory layout

- `text/ES-Spanish/` — all Bible translations and their original nested folder structure.
- `audio/ES-Spanish/` — audio Bible book folders and chapter MP3s.
- `gospel/ES-Spanish/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
